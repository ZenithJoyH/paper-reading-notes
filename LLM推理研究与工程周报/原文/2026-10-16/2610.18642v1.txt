Abstract
The Key-Value (KV) cache constitutes a dom-
inant source of memory consumption during
large language model (LLM) inference, par-
ticularly in long-context and complex reason-
ing scenarios. Existing KV cache quantization
methods have explored different compression
granularities, including layer-wise precision ad-
justment and token-level information preser-
vation. In practical deployment, however, the
key challenge is not merely compression, but
how to allocate limited quantization resources
among heterogeneous precision preservation
strategies under a fixed KV cache memory bud-
get. We propose MultiAlloc, a profiling-guided
precision allocation framework for KV cache
quantization that adaptively distributes limited
quantization resources between layer-wise pre-
cision enhancement and token-wise preserva-
tion. MultiAlloc employs lightweight offline
profiling to characterize layer sensitivity and to-
ken importance, enabling adaptive precision
allocation under a fixed memory constraint.
Guided by the profiled memory–accuracy trade-
off, it automatically derives an effective pre-
cision allocation strategy without online allo-
cation search, and applies the resulting policy
during inference. Extensive experiments on rea-
soning and long-context benchmarks demon-
strate that MultiAlloc consistently improves
over layer-wise, token-wise, and recent multi-
granularity KV cache quantization methods un-
der matched memory budgets across diverse
models, including Mistral, Llama, DeepSeek-
Qwen, and QwQ.

et al., 2024) identifying salient tokens and OTT (Su
et al., 2025) tracing and preserving outlier tokens
at higher precision to reduce token quantization
errors. However, these methods largely overlook
the heterogeneous sensitivity of different layers.
In contrast, KVTuner (Li et al., 2025) and PM-

according to layer or block sensitivity, thereby re-

explicitly preserve token-level heterogeneity. Re-
cent multi-granularity methods, such as KVmix (Li
et al., 2026), further explore the joint adaptation
of layer-wise precision and token-level preserva-
tion by incorporating layer importance and pivotal
context selection. However, their token-level adap-
tation mainly focuses on context selection rather
than precision allocation based on heterogeneous
token importance.
Motivated by these observations, we formulate
KV cache quantization as a precision allocation
problem under a fixed memory budget. We propose
MultiAlloc, a profiling-guided precision allocation
framework that characterizes heterogeneous pre-
cision demands across layers and tokens. Specif-
ically, MultiAlloc employs layer-wise sensitivity
profiling to estimate the precision requirements
of different layers, while token-wise importance
profiling identifies tokens that benefit from high-
precision preservation. Based on these comple-
mentary profiling signals, MultiAlloc adaptively
determines the allocation of limited quantization
resources between layer-wise precision enhance-
ment and token-wise high-precision preservation.
All allocation decisions are derived offline and ap-
plied as a static inference-time policy, eliminating
online allocation search during inference.
We conduct extensive experiments on reasoning
and long-context benchmarks, including GSM8K,
GPQA, and LongBench-v2, using models rang-
ing from 7B to 32B parameters, including Llama-
3-8B-Instruct (Grattafiori et al., 2024), Mistral-
7B-Instruct-v0.3 (Jiang et al., 2023), DeepSeek-
R1-Distill-Qwen-7B/14B (DeepSeek-AI, 2025),
and QwQ-32B (Qwen Team, 2025). The results
demonstrate that MultiAlloc consistently outper-
forms representative layer-wise, token-wise, and
importance-based KV cache quantization methods
under matched KV cache memory budgets, with
robust improvements across different model scales
and both reasoning and long-context tasks.
Our contributions are summarized as follows:
• We reveal heterogeneous precision demands
across layers and tokens in KV cache quanti-
zation, motivating precision allocation under
a fixed KV cache memory budget.
• We propose MultiAlloc, a profiling-guided pre-
cision allocation framework that models layer-
wise sensitivity and token importance to adap-
tively allocate limited quantization resources
between layer precision enhancement and to-
ken preservation.
• Extensive experiments across diverse models
and reasoning and long-context benchmarks
demonstrate that MultiAlloc consistently out-
performs representative layer-wise, token-
wise, and importance-based KV cache quan-

memory budgets.

Related Work
KV Cache Quantization and Precision Alloca-
tion. Recent KV cache quantization methods ex-
plore different strategies to reduce quantization er-
rors while preserving inference quality. KIVI (Liu
et al., 2024) introduces asymmetric low-bit quan-
tization by applying channel-level quantization to
keys and token-level quantization to values. Token-
aware approaches, such as ZipCache (He et al.,
2024) and OTT (Su et al., 2025), preserve salient
tokens at higher precision to mitigate token quanti-
zation errors. Layer-wise methods, including KV-
Tuner (Li et al., 2025) and PM-KVQ (Liu et al.,
2026), allocate mixed precision according to layer
sensitivity. KVmix (Li et al., 2026) further ex-
plores layer- and token-level adaptation, while KV-
COBRA (Ha et al., 2026) studies budget-aware al-
location of compression configurations under fixed
memory constraints. MoE-nD (Sun et al., 2026)
extends KV compression to multiple dimensions
by jointly considering quantization and token re-
duction. However, existing approaches mainly opti-
mize individual compression strategies or configu-
rations, without explicitly modeling heterogeneous
precision demands across granularities or allocat-
ing a shared budget between different precision
preservation strategies.
KV Cache Memory Management. Beyond
quantization, another line of work focuses on man-
aging KV cache memory usage during LLM infer-
ence. PagedAttention (Kwon et al., 2023) improves
2

memory efficiency through virtual memory paging,
while subsequent approaches such as H2O (Zhang
et al., 2023), StreamingLLM (Xiao et al., 2024),
SqueezeAttention (Wang et al., 2024), XKV (Li
et al., 2024), and KVPR (Jiang et al., 2025) reduce
memory pressure through token eviction, retention,
or offloading strategies. These methods primarily
optimize which KV entries to retain or where to
store them, whereas MultiAlloc focuses on allocat-
ing limited quantization resources among differ-
ent precision preservation strategies within the KV
cache representation.
Differentiation of Our Work. Existing KV
cache quantization methods have demonstrated the
effectiveness of preserving important layers or to-
kens at higher precision. However, they mainly fo-
cus on identifying important components or adapt-
ing individual precision strategies, without explic-
itly modeling heterogeneous precision demands
across different granularities. In contrast, MultiAl-
loc introduces a profiling-guided precision alloca-
tion framework that determines how limited quan-
tization resources should be distributed between
layer-wise precision enhancement and token-wise
high-precision preservation under a fixed KV cache
memory budget.

Method
We propose MultiAlloc, a profiling-guided preci-
sion allocation framework for KV cache quantiza-
tion. As illustrated in Figure 2, MultiAlloc consists
of three stages: decoupled precision demand profil-
ing, budget-coupled precision allocation, and static
policy execution.
4.1
Problem Formulation and Overview
We formulate KV cache quantization as a preci-
sion allocation problem under a fixed KV cache
memory budget. Given a Transformer model with
L layers, we aim to determine a static quantiza-
tion policy that allocates limited quantization re-
sources between layer-wise precision enhancement
and token-wise high-precision preservation.

4.5
Static Policy Execution
After the offline allocation stage, MultiAlloc ob-
tains a static precision policy π∗, which specifies
the layer-wise precision configuration and token
preservation configuration. During inference, the
policy is directly applied to incoming KV caches
without additional allocation search.
Specifically, for each layer l, newly generated
KV states are quantized according to the assigned
bit-width q∗
l . Meanwhile, tokens are processed in
groups according to the selected preservation con-
figuration k∗. Within each group, the top-k∗
l tokens
with higher importance scores are stored in high

precision, while the remaining tokens are quantized
using the corresponding layer-wise precision.
The resulting KV cache combines quantized rep-
resentations with preserved high-precision tokens,
enabling efficient long-context inference under the
fixed KV cache memory budget.

5.1
Experimental Setup
We evaluate reasoning and long-context perfor-
mance on five instruction-tuned models span-
ning architectures and scales:
Llama-3-8B-
Instruct (Grattafiori et al., 2024), Mistral-7B-

32B (Qwen Team, 2025). We report accuracy on
GSM8K (Cobbe et al., 2021) and GPQA (Rein
et al., 2024), together with macro-averaged accu-
racy across the six task categories of LongBench-
v2 (Bai et al., 2025). The overall score averages
the GPQA, GSM8K, and LongBench-v2 macro-
average scores. Dataset statistics and evaluation
details are provided in Appendix A. All methods
use identical prompts, tokenization, stopping cri-
teria, and greedy decoding. All experiments are
conducted on NVIDIA A100 GPUs.
For each model, we specify a model-dependent
KV cache budget and evaluate all compressed meth-
ods under the same KV cache memory budget,
with budgets reported in Table 1. We compare
OTT (Su et al., 2025), a representative token-wise
preservation method, PM-KVQ (Liu et al., 2026), a
representative layer-wise mixed-precision method,
KVmix (Li et al., 2026), an importance-guided
hybrid KV cache quantization method, and our
profiling-guided precision allocation framework
MultiAlloc. All methods are implemented within
the same inference framework and follow a unified
KV cache memory-accounting protocol.
5.2
Main Results under Fixed KV Budgets
Table 1 reports the main results under fixed, model-
specific KV cache budgets. For each model, OTT,
PM-KVQ, KVmix, and MultiAlloc are evaluated
under the same memory budget, while FP16 serves
as an uncompressed reference. Across all five mod-
els, MultiAlloc achieves the highest overall accu-
racy among compressed methods, demonstrating
the effectiveness of profiling-guided precision allo-
cation under constrained KV cache budgets.
This advantage remains evident as model scale
increases. On DeepSeek-Qwen-14B, MultiAlloc
matches the best compressed GPQA result and
achieves the strongest performance on GSM8K
and LongBench-v2. On QwQ-32B, it achieves the
best GPQA and LongBench-v2 performance under
the same budget. The smaller gains over exist-
ing methods on larger models arise because their
compressed performance already approaches FP16,
leaving limited headroom for improvement. Never-
theless, MultiAlloc closes 48.2% and 52.1% of the
gaps on the 14B and 32B models, respectively.
Although individual precision preservation
strategies may perform well on specific bench-
marks due to task-dependent sensitivity, MultiAlloc
provides more balanced performance across reason-
ing and long-context tasks by adaptively allocating
quantization resources according to heterogeneous
precision demands.
5.3
Ablation Studies
We conduct ablation studies on Llama-3-8B-
Instruct under a fixed 423 MB KV cache budget.
All variants follow the same evaluation settings as
the main experiments. We perform two analyses:
precision dimension ablation for layer- wise preci-
sion enhancement and token-wise preservation, and
allocation ablation for profiling-guided precision
allocation against manual budget splits.
Table 2 reports the precision preservation abla-
tion results. Layer-only removes token preserva-
tion, while Token-only removes layer-wise preci-
sion enhancement and preserves selected tokens
under a uniform low-bit configuration. MultiAlloc
allocates precision based on both layer-wise and
token-wise precision demands. Removing either
dimension degrades performance, confirming their
complementary roles.
Table 3 compares the profiling-guided allocation
of MultiAlloc with manually specified allocation
strategies between layer-wise precision enhance-
ment and token preservation. The manual policies
adopt 50/50, 65/35, and 35/65 budget splits, while
MultiAlloc determines the allocation through of-
fline profiling. The 65/35 split achieves compa-
rable performance because it happens to closely
match the allocation selected by MultiAlloc under
this specific budget and model setting.

Conclusion
In this work, we formulate KV cache quantization
under a fixed KV cache memory budget as a preci-
sion allocation problem, where limited quantization
resources are adaptively distributed between layer-
wise precision enhancement and token-wise preser-
vation. We propose MultiAlloc, a profiling-guided
framework that characterizes heterogeneous preci-
sion demands across layers and tokens, and derives
a static precision policy through budget-coupled al-
location. Extensive experiments on reasoning and
long-context benchmarks demonstrate that Multi-
Alloc consistently outperforms representative layer-
wise, token-wise, and importance-based KV cache
quantization methods under matched KV cache
8

memory budgets.
7
Limitations
This work focuses on profiling-guided precision
allocation for KV cache quantization under fixed
memory budgets. While MultiAlloc eliminates on-
line allocation search through offline policy deriva-
tion, the profiling stage introduces preprocessing
overhead and requires representative calibration
data. Future work will explore lightweight profil-
ing and improved policy generalization.

A.3
Task-Specific Calibration Protocol
MultiAlloc uses a task-specific calibration set for
each evaluated benchmark. In other words, the
profiling statistics used for GSM8K, GPQA, and
LongBench-v2 are collected from separate calibra-
tion sets corresponding to the target workload. For
a given model and task, the calibration data are
used to estimate the layer-wise precision demand
and token-wise preservation demand required by
the offline allocator. The resulting allocation policy
is then fixed and applied throughout inference for
that workload.
Why
task-specific
calibration?
MultiAlloc
adopts workload-aware offline profiling because
the precision demand of KV cache quantization is
inherently dependent on the workload characteris-
tics. Rather than deriving a single universal allo-
cation policy, MultiAlloc estimates the precision
requirements under the target inference workload,
where different tasks may induce distinct activation
11

distributions and token importance patterns. These
variations affect both the relative quantization sen-
sitivity of Transformer layers and the benefit of
preserving selected tokens in higher precision.
This design is analogous to the calibration pro-
cess commonly used in post-training quantization,
where representative samples are used to character-
ize model behavior before deployment. The calibra-
tion data are only used to collect offline profiling
statistics, including layer-wise quantization sensi-
tivity and token-level preservation demand, rather
than to optimize task-specific model parameters or
access inference labels. As shown in the allocation
analysis in the main paper, different workloads pro-
duce a stable layer-precision backbone with task-
dependent variations in both layer-wise precision
assignment and token-wise high-precision preser-
vation.
Therefore, workload-specific calibration enables
MultiAlloc to allocate the limited KV cache budget
according to the precision demands of the target
deployment scenario instead of relying on a manu-
ally designed fixed allocation strategy. Importantly,
all profiling and allocation decisions are completed
offline. Once the precision policy is generated, in-
ference directly applies the static policy without
online profiling, search, or dynamic reallocation.
A.4
Implementation Details
All experiments are conducted on NVIDIA A100
GPUs with 80 GB of memory. Our implementa-
tion uses Python 3.10, PyTorch 2.5.1, Transform-
ers 4.49.0, and Datasets 3.3.2. All methods use the
same model checkpoints and software environment,
with a batch size of one.
For each benchmark, FP16 and all compressed
methods share identical preprocessing, prompting,
tokenization, decoding, and stopping criteria. The
KV-cache budgets used for the main comparison
are reported in Table 1 of the main paper.
For MultiAlloc, profiling and budget-aware allo-
cation are performed offline. Each model–dataset
pair is profiled for the corresponding target KV-

B
Profiling-based Precision Demand
Estimation
Directly evaluating the downstream performance
of every candidate precision configuration would
require repeated end-to-end inference and is pro-
hibitively expensive.
Instead, MultiAlloc con-
structs lightweight profiling surrogates to charac-
terize the relative precision demand at different
granularities. These surrogates are not intended
to predict the absolute downstream accuracy of
a compressed model. Rather, they provide rela-
tive preference signals among candidate precision-
preservation choices during offline allocation.
Specifically, we separately estimate (i) the sensi-
tivity of different Transformer layers to KV cache
quantization under different bit-widths and (ii) the
benefit of selectively preserving important tokens
in higher precision.

B.3
Complementary Precision Demands
The layer-wise and token-wise profiling stages char-
acterize different dimensions of precision hetero-
geneity in KV cache quantization. Although both
signals reflect the impact of quantization, they cap-
ture complementary precision demands at different
granularities.
The layer-wise precision demand describes the
quantization sensitivity of each Transformer layer
under different bit-width configurations. It deter-
mines where increasing the base precision of the
KV cache can provide larger benefits. In contrast,
the token-wise preservation demand focuses on the
additional benefit of retaining selected tokens in
higher precision within each layer. It identifies
where extra memory allocation can better preserve
important token representations.
These two precision demands correspond to dif-
ferent allocation choices. Layer-wise precision en-
hancement provides broad protection by improving
the base representation quality of sensitive layers,
while token-wise preservation provides selective
protection for a sparse subset of tokens that remain
vulnerable under the assigned layer precision.
Under a fixed KV cache memory budget, these
two strategies compete for the same limited quan-
tization resources. Allocating more memory to
increase layer precision reduces the available bud-
get for token preservation, while preserving more
high-precision tokens limits the memory available
for layer-wise enhancement. Therefore, optimiz-
ing either precision dimension independently can-
not achieve the best allocation under a constrained
memory budget.
The two profiling signals are consequently com-
bined in the subsequent budget-coupled allocation
stage, where MultiAlloc determines how the avail-
able KV cache budget should be distributed be-
tween layer-wise precision enhancement and token-
wise preservation.

E.3
Fixed Split versus Adaptive Allocation
To further examine the necessity of budget cou-
pling, we compare MultiAlloc with manually spec-
ified memory splits between layer-wise precision
enhancement and token preservation.
A fixed split allocates a predefined proportion of
the KV cache budget to each precision preservation
strategy, regardless of the underlying model char-
acteristics, workload, or target memory constraint.
However, the appropriate allocation between the
two dimensions may vary across different deploy-
ment settings.
As shown in Table 3, different manual split ratios
result in distinct performance trade-offs. Although
a manually selected ratio can achieve competitive
performance in certain settings, no fixed split con-
sistently provides the best allocation across the eval-
uated configurations.
In contrast, MultiAlloc determines the budget
distribution between layer-wise precision enhance-
ment and token preservation through offline profil-
ing and budget-coupled optimization. By avoiding
manually predefined budget partitioning, the pro-
posed allocation strategy better adapts the limited
KV cache memory to heterogeneous precision de-
mands under different deployment constraints.
