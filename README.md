## RadiK 笔记内容

- 基数选择如何逐轮定位第 k 大的边界，再筛出 top-k。
- 分层原子操作如何减少全局更新与跨线程块竞争。
- 聚合写回如何一次申请连续输出空间，以及缓冲区容量的设计。
- 共享内存原子操作的访问成本、竞争范围和硬件差异。
- 批量任务调度、地址对齐、自适应缩放与性能实验。
